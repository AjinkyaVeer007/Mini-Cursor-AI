# Mini Cursor IDE - using OpenAI SDK

## Key Features

- Openai sdk
- LLM - Openai
- Tools
- Chain of thoughts prompting

## Functionalities

- Able to develop any design template with modern UI.
- Able to edit the design on go.
- Able to develop any backend project using any stack.

## Step to run

- Clone the repository
- npm install
- add .env file with OPENAI_API_KEY
- npm start and done...!
